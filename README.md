# Software FJ – Fase 4

Sistema en Python para registrar clientes y gestionar reservas de salas,
alquiler de equipos y asesorías especializadas. Los datos se mantienen
en memoria durante la ejecución.

## Cómo ejecutar el programa

En una terminal, desde la carpeta que contiene el archivo:

```bash
python software_fj.py
```

## Resultado de la simulación

La demostración ejecuta 21 operaciones. En la prueba realizada en Google
Colab, 13 operaciones válidas se completaron y 8 operaciones inválidas
se rechazaron de forma controlada. Los 21 casos dieron el resultado esperado.

El programa genera `software_fj.log` con el registro de eventos y errores.
